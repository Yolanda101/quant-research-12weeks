# 第一周作业提交

首次学习时，打开教师发来的注册链接，设置用户名和密码。以后在[学习网站](https://quant-learning-records.zanewan1107.chatgpt.site/course/index.html#week/01/overview)登录，完成六项任务。进度和代码草稿会自动保存。

1. 在作业页补齐代码，运行并检查。
2. 写完三段解释和五条追溯笔记。
3. 打开[学习记录](https://quant-learning-records.zanewan1107.chatgpt.site/course/index.html#week/01/records)，提交作业。
4. 在学习记录中写下问题，查看教师回复。

学习进度、作业和问题仅本人和教师可见。换设备后使用同一账号登录。页面显示同步完成后，记录已保存到账号。尚未同步的修改会保留在当前浏览器，联网后继续同步。导出的作业和记录可留作本地副本。

电脑上也可以检查作业：

```bash
python3 -m pip install -r requirements.txt
python3 scripts/check_assignment.py assignments/week01.py --week 1
```

代码检查核对计算结果和解释是否填写。教师继续阅读文字内容和追溯笔记。
