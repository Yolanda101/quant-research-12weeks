## 02 计算收益率

掌握收益率的分母，手算复利，并认识对数收益率。

### 收益率要说明基数

简单收益率等于期末价格减去期初价格，再除以期初价格。对一笔买入后卖出的交易，分母就是买入价格。本节暂不计费用和现金分配。100 元涨至 110 元，收益率是 10 ÷ 100 = 0.10，写成百分比为 10%。

110 元跌至 99 元，跌幅是 11 ÷ 110 = 0.10，收益率为 −10%。两段价格变化的绝对金额不同，百分比相同。小数 0.10 和百分数 10% 表示相同的比例。Python 中保存 0.10，显示百分比时再乘以 100。

### 连续收益按乘法累计

以 100 元为起点，先上涨 10%，资产变为 100 × 1.10 = 110 元；随后下跌 10%，资产变为 110 × 0.90 = 99 元。累计收益率为 99 ÷ 100 − 1 = −1%。把 10% 和 −10% 直接相加，会忽略第二段的计算基数已经变化。

把每段简单收益率记为 r，每段结束后的资产倍数就是 1 + r。连续两段的累计收益率为两个资产倍数相乘后减 1。只要资产没有额外流入或流出，也没有另行计入的现金分配，就可以按同一方法连接更多观察期。

乘方是相同因子的重复相乘。`1.10 ** 2` 表示连续两期都获得 10% 收益后的资产倍数，结果为 1.21。复利计算处理的是每期的实际基数，练习时不必假定收益恒定。

### 认识对数收益率

对数收益率等于期末价格除以期初价格后取自然对数，记为 ln。它要求价格为正数。Python 自带的 `math` 提供 `log`，本节直接调用，不要求编写函数。`import math` 让代码可以使用这个工具。

对数把连乘变成连加。100、110、99 对应两段对数收益率相加，等于 ln 0.99。这个和约为 −0.010050，不能直接标作简单收益 −1%。用指数函数还原后，再减 1，才得到简单收益率。本周先理解两种收益率的定义，后续每次统计都写明使用哪一种。

### 术语

简单收益率：相对期初价格的变化比例。累计收益率：整个观察区间的收益比例。复利：后续变化按已经变化的资产金额计算。自然对数：以常数 e 为底的对数。

### 预期输出

```text
第一段简单收益： 10.0 %
第二段简单收益： -10.0 %
累计简单收益： -1.0 %
对数收益之和： -0.01005
还原的简单收益： -1.0 %
```

### 独立练习

把三个价格改为 100、90、99。先手算两段简单收益率，再检查累计结果。解释为什么先跌 10% 再涨 10% 仍然没有回到起点。最后计算 90 元回到 100 元需要上涨多少。

### 可运行代码

```python
import math

price_start = 100
price_middle = 110
price_end = 99

return_first = (price_middle - price_start) / price_start
return_second = (price_end - price_middle) / price_middle
cumulative_return = (1 + return_first) * (1 + return_second) - 1
log_first = math.log(price_middle / price_start)
log_second = math.log(price_end / price_middle)
log_total = log_first + log_second
restored_return = math.exp(log_total) - 1

print("第一段简单收益：", round(return_first * 100, 2), "%")
print("第二段简单收益：", round(return_second * 100, 2), "%")
print("累计简单收益：", round(cumulative_return * 100, 2), "%")
print("对数收益之和：", round(log_total, 6))
print("还原的简单收益：", round(restored_return * 100, 2), "%")
```

## 03 生成收益序列

用列表保存价格，用循环逐段计算，并核对累计净值。

### 按观察顺序保存价格

列表可以把多个数值放在一起。`prices = [100, 110, 99, 108, 105]` 保存本周的五个价格。方括号中的数字用逗号分隔。这个列表按观察时间排列，顺序决定了每段收益的含义。

索引表示数据的位置，Python 的索引从 0 开始。`prices[0]` 是 100，`prices[1]` 是 110。`prices[-1]` 表示最后一个价格 105。`len(prices)` 返回列表长度 5。五个价格之间只有四段相邻变化，所以应计算四个收益率。

### 把重复的计算放进循环

`for` 让代码依次处理多个值。`range(1, len(prices))` 在本例中依次给出 1、2、3、4，不包含右侧终点 5。每次用当前位置减去前一位置的价格，再除以前一价格。

循环语句以冒号结束，循环中的代码向右缩进四个空格。缩进决定哪些语句需要重复执行。`returns.append(r)` 把本次算出的收益率追加到列表末尾。后续统计使用未四舍五入的数据，只有显示时才使用 `round`。

### 手算第三段

价格由 99 元变为 108 元，收益率为 9 ÷ 99，约为 9.0909%。这时前两段累计净值为 0.99，乘以本段资产倍数后，净值变为 1.08。起始净值设为 1，最后一个净值为 1.05，对应整个区间 5% 的累计收益。

求和符号 Σ 表示把指定范围的数逐项相加。代码中的 `return_sum = return_sum + r` 就在累计简单收益率之和。本例四段收益率之和约为 6.3131%，累计收益率为 5%。保留这两个数，说明它们各自使用了怎样的计算。

### 让代码判断方向

`if r > 0` 检查收益率是否为正。条件成立时执行对应缩进块；`elif` 检查下一种情况；`else` 处理其余情况。本例把每段标记为上涨、下跌或持平。比较用的 `==` 表示相等，赋值仍使用单个等号。

### 术语

序列：按指定顺序排列的数据。索引：列表元素的位置编号。净值：以统一起点记录的资产倍数。循环：重复执行同一组操作。条件判断：按判断结果选择要执行的代码。

## 04 描述一组收益数据

区分总体和样本，计算均值、中位数及线性插值分位数。

### 说明正在描述什么

总体是研究问题所指的全部对象，样本是实际观察到的部分对象。例如研究某段时期的日收益，若只取得其中四天的数据，这四天就是样本。本周把虚构价格产生的四个收益率作为固定样本，只描述这些数值，不据此估计未来收益。

先保留时间顺序生成收益率，再复制一份数据用于排序。计算累计收益要按原有路径理解；计算中位数和分位数时需要检查排序后的位置。`sorted` 返回排序结果，原始列表保持原样。

### 均值和中位数

均值等于全部观测值的和除以观测数量。本例四段简单收益率之和约为 6.3131%，除以 4，算术均值约为 1.5783%。它描述这四段收益的平均水平，无法代替按复利计算的区间累计收益。

中位数位于排序后的中间位置。样本量为奇数时，取中间一个值；为偶数时，取中间两个值的平均数。四个收益率由小到大约为 −10%、−2.7778%、9.0909%、10%，因此中位数约为 3.1566%。均值和中位数不同，是因为它们使用了不同的计算规则。

### 线性插值分位数

分位数描述排序数据中的位置。本周统一采用线性插值。设样本量为 n，分位比例为 q。先把 n 减 1，再乘以 q，所得 h 是从 0 开始的位置。若 h 是整数，直接取该位置的值；若 h 有小数部分，就按小数部分在相邻两个数之间插值。

计算 25% 分位数时，n 为 4，q 为 0.25，h 为 0.75。它位于索引 0 和索引 1 之间，取前一个值，再加上两值差距的 75%。代入未取整的收益率，结果约为 −4.5833%。75% 分位数的位置是 2.25，结果约为 9.3182%。

代码用 `sum` 求和，用 `//` 做整数除法，用 `%` 求余数，因此 `n % 2 == 0` 可判断数量是否为偶数。`int` 取得非负位置 h 的整数部分，减去整数部分就得到插值比例。分位数有多种计算约定，提交时写明本周的线性插值规则。

### 术语

总体：问题所指的全部对象。样本：实际观察到的对象。算术均值：观测值的和除以数量。中位数：排序后的中间值。分位数：对应指定累计比例的位置值。线性插值：按位置比例计算相邻两值之间的数。

### 预期输出

```text
样本数量： 4
算术均值： 1.5783 %
中位数： 3.1566 %
25.0 % 分位数： -4.5833 %
50.0 % 分位数： 3.1566 %
75.0 % 分位数： 9.3182 %
```

### 独立练习

先脱离代码，手算五个价格的均值和中位数。随后把统计对象改回四个收益率，在笔记中写明数量和单位。用图上的四个点展示 25% 分位数的插值位置，再用一句话区分平均收益率和累计收益率。

### 可运行代码

```python
prices = [100, 110, 99, 108, 105]
returns = []
for i in range(1, len(prices)):
    returns.append((prices[i] - prices[i - 1]) / prices[i - 1])

ordered = sorted(returns)
n = len(ordered)
mean_return = sum(ordered) / n
middle = n // 2
if n % 2 == 0:
    median_return = (ordered[middle - 1] + ordered[middle]) / 2
else:
    median_return = ordered[middle]

print("样本数量：", n)
print("算术均值：", round(mean_return * 100, 4), "%")
print("中位数：", round(median_return * 100, 4), "%")

# 分位数采用线性插值，位置从 0 开始
for q in [0.25, 0.50, 0.75]:
    h = (n - 1) * q
    lower = int(h)
    fraction = h - lower
    upper = lower + 1
    if upper >= n:
        upper = n - 1
    value = ordered[lower] + fraction * (ordered[upper] - ordered[lower])
    print(q * 100, "% 分位数：", round(value * 100, 4), "%")
```

作业的收益题使用同一组五个价格。整理四个相邻观察期的简单收益率，再计算累计收益率、算术均值和中位数。未计费用的累计收益率应为 5%。

作业的费用题另设一笔交易：以 100 元买入 100 份，以 110 元全部卖出，买卖费率均为 0.1%。买入费用为 10 元，卖出费用为 11 元，净利润为 979 元。按模板填写计算，并回答作业页面的三道解释题。

### 独立练习

### 术语

成交金额：成交价格乘以成交数量。费率：费用占成交金额的比例。净利润：卖出净收入减去买入总支出。净收益率：净利润除以明确约定的投入基数。

### 可运行代码

```python
prices = [100, 110, 99, 108, 105]
quantity = 10
fee_rate = 0.001

buy_amount = prices[0] * quantity
buy_fee = buy_amount * fee_rate
buy_outlay = buy_amount + buy_fee
sell_amount = prices[-1] * quantity
sell_fee = sell_amount * fee_rate
sell_proceeds = sell_amount - sell_fee
net_profit = sell_proceeds - buy_outlay
net_return = net_profit / buy_outlay

if net_profit > 0:
    result = "盈利"
elif net_profit < 0:
    result = "亏损"
else:
    result = "持平"

print("买入费用：", round(buy_fee, 2), "元")
print("买入总支出：", round(buy_outlay, 2), "元")
print("卖出费用：", round(sell_fee, 2), "元")
print("卖出净收入：", round(sell_proceeds, 2), "元")
print("净利润：", round(net_profit, 2), "元")
print("净收益率：", round(net_return * 100, 4), "%")
print("结果：", result)
```

答案：C。卖出费用为 1050 × 0.001 = 1.05 元，净收入为 1048.95 元。

   - A. 买入总支出 1001 元
   - B. 卖出成交金额 1050 元
   - C. 净利润 47.95 元

答案：A。本节以包含买入费用的实际支出为投入基数，净收益率为 47.95 ÷ 1001。
