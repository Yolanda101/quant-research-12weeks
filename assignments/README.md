# 第一周作业提交

在[学习网站](https://yolanda101.github.io/quant-research-12weeks/#week/01/overview)完成六项任务，再打开[学习记录](https://yolanda101.github.io/quant-research-12weeks/#week/01/records)。

1. 在作业页补齐代码，运行并检查。
2. 写完三段解释和五条追溯笔记。
3. 导出作业文件和学习记录。
4. 在学习记录页填写学习代号和当前疑问，点击“去 GitHub 提交”。
5. 登录 GitHub，核对内容，将导出的文件拖入正文，点击 Submit new issue。
6. 将生成的 Issue 链接粘贴回学习网站，核验提交。

学习进度和草稿保存在当前浏览器。主动提交后，指导者可以在仓库 Issues 查看并回复。提交会公开显示，可以使用代号。换设备前先导出记录，再在另一设备导入。

电脑上也可以检查作业：

```bash
python3 -m pip install -r requirements.txt
python3 scripts/check_assignment.py assignments/week01.py --week 1
```

代码检查核对计算结果和解释是否填写。指导者继续阅读文字内容和追溯笔记。若把作业放入自己的仓库，可使用 `submissions/学习代号/week01.py` 或 `submissions/学习代号/week01.ipynb`，查看 Actions 中的“检查作业”。
